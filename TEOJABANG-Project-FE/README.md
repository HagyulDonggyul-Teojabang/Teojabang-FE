## 현재 구현 상태

MVP 3가지 핵심 기능을 **프론트엔드 데모 수준**으로 구현 완료했다. AI 분석은 실제 Vision API 대신 샘플 빈집 데이터와 규칙 기반 점수 산출로 동작한다.

| 기능                | 상태      | 설명                                                |
| ------------------- | --------- | --------------------------------------------------- |
| 영농 조건 입력      | ✅ 완료   | 희망 지역·작목·농지 크기·예산·차량·창고·마당        |
| AI 분석·적합도 순위 | ✅ 완료   | 샘플 빈집 3채 비교, 점수·순위·추천 이유 출력        |
| 항목별 상태 진단    | ✅ 완료   | 양호 · 주의 · 위험 · 현장 확인 필요                 |
| 초기 정착비용 계산  | ✅ 완료   | 보증금·연간 임대료·농지·영농 준비비·농기계 합산     |
| 현장 방문 신청      | ✅ 완료   | 방문 일시·연락처 입력, 접수 확인, 현장 체크리스트   |
| 단계별 네비게이션   | ✅ 완료   | 조건 입력 → AI 분석 → 정착비용 → 방문 신청 4단계 UI |
| Vision API 연동     | ⬜ 미구현 | Stretch — 실제 사진 분석 API 연동 예정              |
| 백엔드 API          | ⬜ 미구현 | 방문 신청·빈집 데이터 서버 연동 예정                |

### 샘플 빈집 3채

| 빈집                         | 특징                                |
| ---------------------------- | ----------------------------------- |
| 서귀포 감귤밭 인근 단독주택  | 상태 양호, 트럭 진입·창고·마당 보유 |
| 제주시 근교 소규모 농가 주택 | 대중교통 접근성 우수, 창고 없음     |
| 성산 일출봉 인근 전통 가옥   | 넓은 마당·창고, 수리 필요 항목 다수 |

## 사용자 플로우

```
1. 조건 입력      → 희망 지역·작목·농지·예산·차량·창고·마당 입력
2. AI 분석        → 빈집 3채 적합도 순위·항목별 상태 진단 확인, 후보 선택
3. 정착비용       → 선택 빈집 기준 초기 정착비용 항목별 내역 확인
4. 방문 신청      → 방문 일시·연락처 입력 → 접수 확인 + 현장 체크리스트
```

## 로컬 실행 방법

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 프로덕션 빌드
npm run build

# 빌드 결과 미리보기
npm run preview

# 린트 검사
npm run lint
```

개발 서버 실행 후 브라우저에서 표시되는 로컬 URL(기본: `http://localhost:5173`)로 접속한다.
