## 해결하려는 문제

### 문제 설명

2024년 제주도 빈집 실태조사에서는 총 **1,159호**의 빈집이 확인됐다. 이 중 바로 활용할 수 있는 1등급 빈집은 10%, 수리 후 활용할 수 있는 2등급 빈집은 73%로, 전체의 **83%**가 철거보다 활용을 검토할 수 있는 상태다.

제주도 역시 2026년부터 빈집 소유자가 주택을 5년 이상 무상으로 제공하면 한 채당 최대 5천만 원 범위에서 리모델링한 뒤 청년·신혼부부 등을 위한 공공임대주택으로 공급하는 시범사업을 추진하고 있다.

다만 통계상 확인된 빈집 1,159호가 모두 임대·매매 가능한 매물이라는 뜻은 아니다. 실제 활용을 위해서는 소유자의 동의, 소유관계 확인, 매물 등록 등의 과정이 먼저 필요하다. **따라서 이번 MVP에서는 제주에 있는 모든 빈집을 발굴하는 문제까지 해결하지 않는다.**

우리가 해결하려는 문제는 **소유자·공인중개사·지자체를 통해 활용 의사가 확인되고 등록된 빈집**도, 예비 청년농이 방문 전에 집의 실제 상태와 수리 부담, 자신의 영농조건과의 적합성을 판단하기 어렵다는 점이다.

기존 빈집 정보는 주로 위치·면적·가격·외관 사진을 제공한다. 하지만 예비 청년농이 실제로 정착하려면 다음과 같은 정보가 추가로 필요하다.

- 벽·천장·바닥·창호·화장실 등 눈에 보이는 노후 상태
- 곰팡이·누수 흔적 등 수리가 의심되는 부분
- 수리해야 할 항목과 참고할 수 있는 예상 비용 범위
- 농지까지의 거리와 이동시간
- 1톤 트럭이나 소형 농기계의 진입·주차 가능 여부
- 농기구·비료·수확물 등을 둘 수 있는 창고와 마당 유무
- 수도·전기·난방·인터넷 등 기본적인 생활 기반

청년농에게 집은 단순한 주거공간만이 아니라 **농지와 작업을 연결하는 생활 거점**이 될 수 있다. 같은 가격의 집이라도 농지와 멀거나 차량 진입이 어렵고 보관공간이 없다면 실제 영농생활에는 적합하지 않을 수 있다.

### 핵심 문제 정의

> **"활용 의사가 확인된 제주 농촌 빈집도 집의 실제 상태와 예상 수리 부담, 청년농의 영농·생활 조건이 같은 기준으로 정리되어 있지 않아, 예비 청년농이 현장 방문 전 어떤 집을 먼저 확인해야 할지 판단하기 어렵다."**

### 이 문제를 선택한 이유

- 제주의 농촌 빈집 문제는 단순히 빈집의 수가 많다는 문제로 끝나지 않는다. 활용 가능한 빈집이 실제 거주자에게 연결되려면 해당 집이 현재 살 수 있는 상태인지, 어떤 수리가 필요하며 얼마나 부담해야 하는지를 먼저 판단할 수 있어야 한다.
- '오지는 오지다' 유튜브 대표 김현우씨 서면 의견: 공개된 정보와 실제 현장의 상태가 다른 경우가 많으며, 예비 귀농·귀촌인은 **즉시 거주 가능 여부, 누수·곰팡이, 리모델링 비용, 주변 환경, 소유관계** 등을 특히 궁금해한다.
- 사진을 활용한 AI 분석은 예상 범위를 제시하고, 사진만으로 판단할 수 없는 부분을 현장 확인 항목으로 안내하면 실제 빈집 탐색에 도움이 될 수 있다.
- 자체 설문에서도 집의 내부 상태, 수리 범위, 실제 총비용, 원하는 지역의 매물 부족 등에 관한 불편이 반복적으로 언급됐다.
- 제주는 다른 지역에 거주하는 사람이 빈집을 확인하려면 항공·숙박·현지 이동과 시간이 필요하다. 방문 후 집의 상태가 예상과 다르면 탐색 비용이 커진다.

## 핵심 사용자

### 대상

**제주 귀농을 결정했거나 적극적으로 준비하고 있고**, 희망지역 또는 작목은 어느 정도 정했지만 **아직 살 집을 확정하지 못한 예비·초기 청년농**

| 구분                 | 내용                                                                                                                                            |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| **연령/상황**        | 청년농 지원정책 주요 대상인 만 18~39세. 제주 외 지역 거주 또는 제주 연고가 적어 빈집을 자주 확인하기 어려운 사람                                |
| **주요 생활 환경**   | 귀농 준비와 기존 직장·교육을 병행, 정해진 제주 방문 일정 안에 여러 주택과 농지를 확인해야 함                                                    |
| **자주 놓이는 맥락** | 온라인에서 매물을 찾고 사진·가격을 비교한 뒤, 후보 주택을 골라 제주에 방문하거나 공인중개사에게 문의                                            |
| **겪는 제약/불편**   | 내부 상태와 수리 범위를 알기 어렵고, 집마다 제공하는 정보가 달라 비교하기 어려움. 농지 거리·차량 진입·창고·마당 등 영농 조건도 따로 확인해야 함 |

### 사용자가 아닌 사람

- 귀농 여부를 막연하게 고민하고 있어 지역과 작목을 전혀 정하지 않은 사람
- 이미 주거지를 확정한 농가
- 관광·숙박·세컨하우스 목적으로 빈집을 찾는 사람
- 일반적인 도시주택을 찾는 사람

## 문제 상황 및 원인 분석

### 문제 상황 1 — 빈집의 실제 상태와 수리 부담을 알 수 없다

제주 외 지역에 거주하는 예비 청년농이 등록된 빈집을 온라인에서 확인한다. 위치·면적·가격과 외관 사진은 있지만 벽·천장·창호·화장실 등 **내부 상태를 같은 기준으로 확인하기 어렵다.**

사진에 보이는 변색이 단순한 얼룩인지 곰팡이·누수 흔적인지, 창호와 바닥을 교체해야 하는지, 수리에 수백만 원이 필요한지 수천만 원이 필요한지 판단하기 어렵다. 결국 **직접 방문하거나 업체의 현장 견적**을 받아야만 해당 집을 후보에서 제외할지 결정할 수 있다.

### 문제 상황 2 — 빈집 3채 중 어떤 집이 자신의 영농생활에 적합한지 비교하기 어렵다

비슷한 가격의 빈집 3채가 있어도 사용자마다 필요한 조건은 다르다.

- **감귤농사 + 1톤 트럭:** 농지까지 이동시간, 차량 진입 가능 여부, 창고 중요
- **차량 없음 + 소규모 농사:** 대중교통과 생활시설 접근성 중요

현재는 이러한 조건이 매물별로 동일하게 정리되어 있지 않다. 사용자는 여러 사이트와 공인중개사의 설명을 직접 대조하고, 결국 **모든 집을 방문**해야 한다.

### 현재의 해결 방식과 한계

| 현재 해결 방식                       | 한계                                                                  |
| ------------------------------------ | --------------------------------------------------------------------- |
| 빈집애·그린대로 등 빈집 플랫폼 검색  | 매물 발견에는 도움, 사진·수리 항목이 같은 기준으로 표시되지 않음      |
| 네이버부동산·당근 등 일반 매물사이트 | 영농 조건과 빈집 상태를 함께 비교하기 어려움                          |
| 지역 공인중개사·지인 문의            | 사람마다 기준이 달라 정량적 비교 어려움                               |
| 직접 현장 방문·업체 견적             | 정확하지만, 방문 전에 어떤 집에 시간·비용을 쓸지 먼저 결정하기 어려움 |

### 핵심 원인

> **"거래 가능한 빈집의 상태와 예비 청년농의 영농·생활 조건을 동일한 기준으로 구조화하고 비교하는 정보체계가 없기 때문이다."**

빈집의 상태는 사진과 현장 설명에 흩어진 비정형 정보이고, 사용자의 영농계획도 작목·차량·농지·예산·필요공간 등에 따라 달라지는 비정형 정보다. 기존 서비스는 빈집을 목록으로 보여주지만, **두 정보를 같은 기준으로 바꾸어 비교하지 않는다.**

## 경쟁 서비스 비교

| 서비스·정책                   | 하는 일                                                       | 우리 서비스와의 차이                                                                             |
| ----------------------------- | ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| **빈집애**                    | 소유자가 활용에 동의한 빈집의 위치·면적·상태 등 매물정보 제공 | 빈집 현황과 매물 연결이 중심, 사진 기반 수리항목 분석·청년농 영농조건 비교 기능 없음             |
| **농촌빈집은행(그린대로)**    | 귀농·귀촌 희망자에게 농촌 빈집 매매·임대정보 제공             | 매물 탐색 중심, 빈집별 수리 부담과 사용자 조건을 같은 기준으로 비교하기 어려움                   |
| **강진품애**                  | 소유자가 제공한 빈집을 지자체가 리모델링해 저렴하게 임대      | 지자체가 빈집을 직접 정비해 공급하는 공공주거 정책                                               |
| **제주 빈집 공공임대**        | 무상 제공된 빈집을 리모델링해 청년·신혼부부 등에게 공급       | 공공임대주택 조성 정책, 개인의 작목·차량·창고 등 영농조건과 빈집을 대조하지 않음                 |
| **다자요**                    | 제주 빈집을 장기 임차하고 직접 리모델링해 숙박시설로 운영     | 관광·숙박 목적, 귀농인의 주거·영농 정착 서비스 아님                                              |
| **농사로 / 귀농귀촌종합센터** | 작목·재배기술·교육·귀농정책 및 상담정보 제공                  | 농업정보와 주거매물 정보가 분리되어 있어, 특정 빈집이 사용자 영농생활에 적합한지 판단하기 어려움 |

기존 서비스는 크게 **빈집 정보를 보여주는 서비스**와 **지자체·기업이 직접 고쳐 공급하는 방식**으로 나뉜다. 우리 서비스는 이 사이에서 **등록된 빈집의 상태를 분석하고, 예비 청년농이 어떤 집을 먼저 확인할지 결정하도록 돕는 역할**을 한다.

## 시장성

- 2024년 전국 빈집 약 **13만 4천 호**, 이 중 약 **8만 7천 호**는 활용 가능한 상태로 조사됨 → 제주에서 검증한 방식은 다른 농촌지역에도 적용 가능
- 실제 대상은 소유자가 활용에 동의하고 임대·매매 또는 공공사업 연계가 가능한 빈집
- **초기:** 제주 예비·초기 청년농 대상 검증
- **확장:** 제주 청년농업인 → 귀농·귀촌 희망자 → 전국 농촌지역 → 지자체·귀농지원기관·공인중개사
- **MVP:** 청년농에게 무료 제공
- **향후 수익모델:** 지자체·귀농지원기관·공인중개사에 빈집 표준등록, 사진 분석, 수요자 비교·추천 기능 이용료 또는 빈집 분석 용역 (기관 구매 의사는 캠프 멘토링·인터뷰로 검증 예정)

## 해결 방향

1. 소유자·공인중개사·지자체가 표준 촬영 가이드에 따라 등록한 빈집 사진을 AI가 분석해, 사진에서 확인 가능한 노후 상태를 **양호 · 주의 · 위험**으로 진단한다.
2. 사용자가 입력한 희망지역·작목·예산·차량·창고·마당 등의 조건과 빈집 3채의 분석 결과를 비교해 **적합도 순위, 추천 이유, 주거 관련 초기 정착비용**을 제공한다.
3. 사용자가 빈집을 선택하면 **현장 방문을 신청**할 수 있으며, 사진으로 판단할 수 없었던 항목은 **현장에서 확인할 체크리스트**로 안내한다.

### 사용자가 얻게 될 변화

| 기존                                           | 서비스 이용 후                                           |
| ---------------------------------------------- | -------------------------------------------------------- |
| 외관 사진과 가격만 보고 방문 여부 결정         | 사진 분석 결과와 집 상태 진단을 보고 방문 여부 결정      |
| 여러 빈집을 모두 직접 방문                     | 조건에 맞는 가능성 높은 후보부터 방문                    |
| 집마다 정보 형식이 달라 비교하기 어려움        | 빈집 3채를 동일한 항목으로 비교                          |
| 임대료만 확인하고 실제 초기 부담을 알기 어려움 | 임대료에 농지·영농 준비비까지 합쳐 총 초기 정착비용 확인 |
| 농지 거리·차량 진입·창고 등을 따로 문의        | 영농·생활 조건을 적합도에 함께 반영                      |
| 현장에서 무엇을 확인해야 할지 모름             | AI가 판단하지 못한 항목을 체크리스트로 확인              |

## MVP 핵심 기능

> 캠프에서는 서비스 전체 개발보다 **핵심 기능 MVP 3가지**에 집중한다.

### 사용자 플로우

```
조건 입력 → AI 분석·적합도 순위 → 정착비용 확인 → 현장 방문 신청
```

### Core — AI 기반 제주 빈집 사진 분석 및 적합도 순위 추천

|                 | 내용                                                                                                                                                                           |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **유저 스토리** | 예비·초기 청년농이 어느 빈집을 먼저 보러 갈지 정하기 위해, 자신의 영농 조건과 등록된 빈집 사진을 AI가 분석해 빈집 3채의 적합도 순위와 집 상태를 확인                           |
| **Input**       | 희망지역·작목·농지 크기·예산·차량·창고/마당 필요 여부 + 빈집 3채 사진·기본정보                                                                                                 |
| **AI 역할**     | ① 청년농 정착 조건과 빈집 데이터 분석 ② 사진 항목(지붕·창문·난방·누수·곰팡이·노후도 등)을 양호·주의·위험 진단 ③ 확인 불가 항목은 "현장 확인 필요" 표시 ④ 적합도 점수·순위 산출 |
| **Output**      | 빈집 3채 적합도 순위 + 항목별 상태 진단 화면                                                                                                                                   |
| **완료 기준**   | 사용자가 희망 조건을 입력하면, AI가 빈집 3채의 적합도 순위와 집 상태 진단을 화면에 정상 출력                                                                                   |

### Supporting 1 — 현장 방문 및 상담 신청

|               | 내용                                                                                |
| ------------- | ----------------------------------------------------------------------------------- |
| **Input**     | 추천받은 3채 중 선택한 빈집 + 방문 희망 일시                                        |
| **Output**    | 방문 신청 접수 확인 + 방문 시 확인할 체크리스트 (Core의 "현장 확인 필요" 항목 포함) |
| **완료 기준** | '현장 방문 신청' 클릭 시 접수 내역과 필수 체크리스트가 안내 화면으로 정상 출력      |

### Supporting 2 — 초기 정착비용 계산

|               | 내용                                                                                                   |
| ------------- | ------------------------------------------------------------------------------------------------------ |
| **Input**     | 작목·농지 크기 등 사용자 조건 + 선택한 빈집 임대·매입 정보 + 지역 농지 시세 데이터                     |
| **Output**    | 농지·영농 초기비·농기계·임대료 합산 총 초기 정착비용 + 항목별 내역 (수리비는 "현장 견적 후 별도" 안내) |
| **완료 기준** | 선택한 빈집과 영농 조건 기준으로 항목별 초기 정착비용이 화면에 정상 출력                               |

### Stretch 기능 (시간 여유 시)

- 사진 기반 수리비 예측
- 사진 분석 정밀화
- 농지 매칭
- '제주 미리 살아보기' 단기 체류 연계
- 청년창업농 지원정책 맞춤 매칭
- 지역 청년농 네트워크
- 빈집 소유자 직접 등록 및 전국 농촌 확장
